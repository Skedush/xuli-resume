## When Populating This Repo

If building a CV/résumé application, document:

- **Tech stack**: What framework (React, Vue, vanilla HTML/CSS, LaTeX-based, etc.)
- **Build commands**: `npm install`, `npm run dev`, `npm run build`, etc.
- **Entry point**: How the CV is rendered (e.g., `index.html`, `src/App.tsx`)
- **Styling approach**: Tailwind, CSS modules, custom CSS, print stylesheets
- **Content structure**: Where CV data lives (YAML, JSON, Markdown, or CMS)
- **Deployment**: How to deploy (GitHub Pages, Vercel, Netlify, etc.)
- **Single-file rendering**: How to preview/print just the CV

## Generic CV Project Notes

- Use browser print (`Ctrl+P` / `Cmd+P`) for PDF export
- Include `@media print` styles for clean printed output
- Keep content in structured data files separate from presentation code
