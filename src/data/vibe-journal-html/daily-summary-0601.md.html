一、当日核心事件

1. Git push HTTPS 经 mihomo 代理 GnuTLS 握手失败 → 切换 SSH

  • 症状：git push 经 mihomo 代理（127.0.0.1:7890）时 GnuTLS 握手失败；curl github.com 同等条件正常
  • 根因：git/libcurl 和 mihomo 之间 HTTPS CONNECT 隧道的 TLS 兼容性问题
  • 三种解法：
    1. mihomo config.yaml 加 DOMAIN-SUFFIX,github.com,DIRECT（绕过代理直连）
    2. 生成 SSH key + 切换 remote 为 SSH URL（采用此方案）
    3. GitHub Personal Access Token + git credential helper
  • 落地：生成 ~/.ssh/id_ed25519，公钥加到 GitHub，remote 改 git@github.com:Skedush/xuli-resume.git
  • 验证：PR feat/vibe-journal-downstream push 成功

2. xuli-resume GPU 占用优化

  • 根因：BackgroundEffects 组件两层 blur-3xl 大光晕 + 永久 infinite CSS 动画，叠加 Framer Motion 合成层
  • 优化：
    • filter: blur(...) → radial-gradient（浏览器预栅格化，停止每帧高斯模糊）
    • 关键帧从 left/top → transform: translate3d(...)（走 GPU 合成层）
    • 加 will-change: transform / contain: strict
    • 60vmin 替代 36rem（CSS 长度解析更轻）
    • prefers-reduced-motion 加 display: none 守卫
  • 验证：GPU 占用降一半
  • 排除项：Remotion 不适用（视频离线渲染框架，与实时网页背景动画是两种开销模型）

5. Hermes 性格 + token 节省配置

  • 会话级斜杠：/personality terse / /reasoning minimal / /verbose off / /fast on

6. Hermes 多 Profile 配置共享

  • 误区：把 root ~/.hermes/config.yaml cp 到所有 profile（抹平 model 隔离）
  • 正确做法：通用项放根 config，profile 单独覆写 model.* 字段
    hermes -p work config set model.default gpt-5.4
hermes -p personal config set model.default claude-sonnet-4
  • 边界：profile 路径 ~/.hermes/profiles/<name>/，default 是符号链接回根

7. default profile "Skills: 1" 之谜

  • 现象：hermes profile show default 显示 Skills: 1，builder 显示 127
  • 根因：default profile 路径是 ~/.hermes，没有 skills/ 子目录；它只读 builtin 的 hermes-agent 这一个
  • 全局 ~/.hermes/skills/ 是一堆 symlink 到 ~/.cc-switch/skills/，symlink 目标大多空目录或 sub-skill
  • builder 有 ~/.hermes/profiles/builder/skills/ 所以显示 127
  • 修复：给 default 挂 symlink 到 ~/.cc-switch/skills

四、上下游契约关键设计

上游（vibe-coding-journal）
  ├─ LLM 写 deliverable（producer）
  ├─ LLM 末尾加 json skills_used 块

  └─ deliverables/*.md + deliverables/*.meta.json

下游（xuli-resume）
  ├─ 纯脚本：fs + marked + 正则
  ├─ Tier 1：解析 json skills_used 块
  ├─ Tier 2：SKILLS.md alias 全文匹配
  ├─ Tier 3：未识别 token 写入 meta 的 unrecognizedTokens
  ├─ auto-register：新技能归一化 + 写 skills.json
  └─ 输出：vibe-journal-meta.json + skills.json 增量
